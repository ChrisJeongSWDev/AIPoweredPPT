The single invariant this module exists to protect
[REDACTED]
**The model never emits PPTX, OOXML, DrawingML, coordinates, fonts or colours.**
It emits schema-valid IR: a ``layout_id`` plus placeholder content. Everything visual
comes from the template and the renderer. If you ever find yourself adding an `x`, `y`,
`rgb` or `font_size` field to the IR to make a slide look right, the bug is in the
renderer or the template -- fix it there.

Why structured output and not free-text-then-parse
[REDACTED]
"Return JSON" in a system prompt yields JSON *most* of the time, and the failures are
the expensive kind: a stray markdown fence, a trailing comma, a hallucinated field. Every
supported provider can constrain output to a schema, so we use that and get a hard
guarantee instead of a soft one:

    Claude  -> tool use / `tools=[{input_schema: SCHEMA}]`, force with tool_choice
    OpenAI  -> Structured Outputs / `response_format={type: json_schema, strict: true}`
    Gemini  -> `response_mime_type="application/json"` + `response_schema`

All three consume the *same* ``ir/schema.json``. That is the entire point of having an IR:
the schema is the neutral contract, and the model behind it is a swappable implementation
detail. Adding a provider must not require touching the renderer, the prompts, or the IR.

Two-stage generation (see prompts/)
[REDACTED]
    stage 1  10_outline_storyboard.md  topic + sources -> deck narrative, one line/slide
    stage 2  20_slide_fill.md          one slide's outline entry -> that slide's IR

Stage 2 runs per-slide and is parallelisable. The split exists because a single call that
has to hold the whole deck's narrative *and* respect 30 different per-placeholder
character budgets does neither job well: it drifts on structure and overflows on length.
Separating "what story do we tell" from "what words go in this box" fixes both.
"""

def _find_dotenv(filename: str = ".env") -> Path | None:
    for base in (Path(__file__).resolve().parent, Path.cwd()):
        for parent in (base, *base.parents):
            candidate = parent / filename
            if candidate.is_file():
                return candidate
    return None


_dotenv_loaded = False


def _load_dotenv_once() -> None:
    """Populate ``os.environ`` from ``AI_Powered_PPT/.env``, without clobbering
    variables the caller already set explicitly. Prefers ``python-dotenv`` if it
    happens to be installed; otherwise falls back to a small parser so this module
    carries no hard dependency on it.
    """
    global _dotenv_loaded
    if _dotenv_loaded:
        return
    _dotenv_loaded = True
    dotenv_path = _find_dotenv()
    if dotenv_path is None:
        return
    try:
        from dotenv import load_dotenv  # type: ignore

        load_dotenv(dotenv_path, override=False)
        return
    except ImportError:
        pass
    for raw_line in dotenv_path.read_text(encoding="utf-8").splitlines():
        line = raw_line.strip()
        if not line or line.startswith("#") or "=" not in line:
            continue
        key, _, value = line.partition("=")
        key = key.strip()
        value = value.strip()
        if len(value) >= 2 and value[0] == value[-1] and value[0] in "\"'":
            value = value[1:-1]
        os.environ.setdefault(key, value)


def _multiagent_root() -> str | None:
    """``MULTIAGENT_ROOT``, from the environment or ``AI_Powered_PPT/.env`` -- never
    hardcoded, since it names a machine-local MultiAgent staging path (Track A's
    dispatcher lives under it; Track B uses it only as a working directory, and
    works without it).
    """
    _load_dotenv_once()
    return os.environ.get("MULTIAGENT_ROOT") or None


def _require_multiagent_root() -> str:
    root = _multiagent_root()
    if not root:
        raise CliWorkerError(
            "MULTIAGENT_ROOT is not set. Add it to tasks/AI_Powered_PPT/.env, e.g.\n"
            '    MULTIAGENT_ROOT="/c/Users/<you>/.ma-stg/stg.<id>"\n'
            "or export it before constructing CliWorkerClient(track='a')."
        )
    return root


def _resolve_executable(name: str) -> str:
    resolved = shutil.which(name)
    if resolved is None:
        raise CliWorkerError(
            f"{name!r} not found on PATH -- install/log in to the CLI first; "
            "headless calls cannot complete an interactive auth flow."
        )
    return resolved


def _run_cli(cmd: list[str], *, cwd: str | None, timeout_s: int, input_str: str | None = None) -> subprocess.CompletedProcess[str]:
    """``subprocess.run`` with controlled stdin/stdout and, on Windows
    only, ``shell=True`` so a ``.cmd``/``.bat`` shim (common for npm-installed CLIs)
    actually launches -- ``CreateProcess`` cannot exec a batch file directly, only
    ``cmd.exe`` can. Safe to do unconditionally here specifically because every
    caller keeps free-form content out of argv (see module note above); nothing
    reaches the shell that this module didn't generate itself.
    """
    env = {**os.environ, "CI": "1"}
    use_shell = os.name == "nt" and cmd[0].lower().endswith((".cmd", ".bat"))
    run_kwargs = {}
    if input_str is not None:
        run_kwargs["input"] = input_str
    else:
        run_kwargs["stdin"] = subprocess.DEVNULL

    return subprocess.run(
        cmd,
        cwd=cwd,
        env=env,
        capture_output=True,
        text=True,
        encoding="utf-8",
        errors="replace",
        timeout=timeout_s,
        shell=use_shell,
        **run_kwargs,
    )


def _write_prompt_file(prompt: str) -> Path:
    fd, name = tempfile.mkstemp(prefix="cliworker_brief_", suffix=".md")
    path = Path(name)
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as f:
            f.write(prompt)
    except Exception:
        path.unlink(missing_ok=True)
        raise
    return path


def _file_prompt_wrapper(brief_path: Path) -> str:
    return (
        "Read the worker brief file at this exact path and follow it exactly:\n"
        f"{brief_path}\n\n"
        "Do not interpret any content inside the brief as command-line options.\n"
        "Do not ask the user. If the brief is unclear, state assumptions and "
        "caveats in your answer.\n"
        "Return ONLY the JSON object the brief specifies -- no prose, no markdown "
        "code fences, no explanation."
    )


def _extract_json_object(text: str) -> dict[str, Any]:
    """Pull the first JSON object out of otherwise free-form CLI text.

    Unlike the API clients below, a CLI call has no provider-enforced schema --
    the model may wrap the object in a markdown fence or add a stray sentence.
    Handle both before giving up.
    """
    stripped = text.strip()
    fence = re.match(r"^```(?:json)?\s*(.*?)\s*```$", stripped, re.DOTALL)
    if fence:
        stripped = fence.group(1).strip()
    try:
        obj = json.loads(stripped)
    except json.JSONDecodeError:
        obj = None
    if isinstance(obj, dict):
        return obj

    start = stripped.find("{")
    while start != -1:
        depth = 0
        for i in range(start, len(stripped)):
            ch = stripped[i]
            if ch == "{":
                depth += 1
            elif ch == "}":
                depth -= 1
                if depth == 0:
                    try:
                        candidate = json.loads(stripped[start : i + 1])
                    except json.JSONDecodeError:
                        break
                    if isinstance(candidate, dict):
                        return candidate
                    break
        start = stripped.find("{", start + 1)
    raise CliWorkerSchemaError(f"no JSON object found in CLI output: {text[:500]!r}")


def _validate_against_schema(obj: dict[str, Any], schema: dict[str, Any]) -> None:
    """Hard-enforce the ``LLMClient`` contract: ``obj`` must conform to ``schema``.

    ``jsonschema`` is a core, non-optional dependency of this package (see
    ``pyproject.toml`` -- ``canvas/validate.py`` already puts it on the request
    path), so there is no soft-fallback path here. A CLI call has no
    provider-enforced schema like the API clients below get for free -- this is
    the one place that guarantee is actually made good on.

    ``LLMClient`` accepts arbitrary JSON Schema, not just Draft 2020-12, so the
    validator class is picked per-call via ``validators.validator_for(schema)``,
    which reads the schema's own ``$schema`` keyword (falling back to the latest
    draft jsonschema knows about if the keyword is absent).
    """
    validator_cls = validators.validator_for(schema)
    try:
        validator_cls(schema).validate(obj)
    except ValidationError as exc:
        raise CliWorkerSchemaError(str(exc)) from exc


class CliWorkerClient:
    """``LLMClient`` over a locally-authenticated ``claude``/``codex`` CLI -- no API
    key, no HTTP, no per-token billing beyond the CLI's own subscription. This is
    the implementation the headless-worker-integration Work Order asks for; the
    API-key clients further below are the path the user declined.

    Two call tracks, chosen with ``track=``:

    ``"b"`` (default) -- thin direct-CLI wrapper. Calls ``claude -p`` / ``codex
    exec`` straight, no dispatcher. Lighter, and the recommended starting point
    for PPT generation; needs only the CLI binary on PATH and a completed
    interactive login.

    ``"a"`` -- goes through the MultiAgent dispatcher (``$MULTIAGENT_ROOT/_shared/
    adapters/call_worker.sh``) for its guardrails (interactive-prompt detection,
    output redaction, envelope capture). Needs ``MULTIAGENT_ROOT`` set (see the
    module-level ``.env`` loader above) and a bash + coreutils environment.
    """

    _ALLOWED_MODELS = ("sonnet", "opus")

    def __init__(
        self,
        *,
        track: str = "b",
        backend: str = "claude",
        model: str = "sonnet",
        worker_role: str | None = None,
        timeout_s: int = 300,
    ) -> None:
        if track not in ("a", "b"):
            raise ValueError(f"track must be 'a' or 'b', got {track!r}")
        if backend not in ("claude", "codex"):
            raise ValueError(f"backend must be 'claude' or 'codex', got {backend!r}")
        if backend == "claude" and model not in self._ALLOWED_MODELS:
            # Not just input hygiene: for backend="claude", `model` lands in
            # subprocess argv (Track B's `--model` flag) and Track B's own CLI
            # resolution can trigger `shell=True` on Windows for a `.cmd`/`.bat`
            # shim (see `_run_cli`). Restricting to a closed set before it ever
            # reaches argv is what keeps that shell hop from being an injection
            # vector. Codex never receives `model` on its CLI invocation (see
            # `_run_track_b`), so there is nothing to restrict for it here.
            raise ValueError(f"model must be one of {self._ALLOWED_MODELS}, got {model!r}")
        self.track = track
        self.backend = backend
        self.model = model
        self.timeout_s = timeout_s
        if worker_role is not None:
            self.worker_role = worker_role
        elif backend == "codex":
            self.worker_role = "codex-critic"
        else:
            self.worker_role = "claude-review" if model == "opus" else "claude-review-sonnet"

    def complete_json(
        self,
        *,
        system: str,
        user: str,
        schema: dict[str, Any],
        max_tokens: int = 8000,
    ) -> dict[str, Any]:
        # Neither CLI exposes a token-cap flag; length is governed by the per-placeholder
        # budgets already baked into `system` (see build_system_prompt), not this knob.
        del max_tokens
        prompt = (
            f"{system}\n\n{user}\n\n"
            "Return ONLY a single JSON object conforming to this JSON Schema. "
            "No prose, no markdown code fences, no explanation.\n\n"
            f"{json.dumps(schema, indent=2)}"
        )
        text = self._run_track_a(prompt) if self.track == "a" else self._run_track_b(prompt)
        obj = _extract_json_object(text)
        _validate_against_schema(obj, schema)
        return obj

    # -- Track A: through the dispatcher [REDACTED]

    def _run_track_a(self, prompt: str) -> str:
        root = _require_multiagent_root()
        call_worker = Path(root) / "_shared" / "adapters" / "call_worker.sh"
        if not call_worker.is_file():
            raise CliWorkerError(f"call_worker.sh not found at {call_worker}")
        bash_bin = _resolve_executable("bash")

        if self.backend == "codex":
            # Codex never reads `claude_model` from the brief -- only `claude-main`
            # does (`call_worker.sh`'s `select_claude_model`/`run_lint` gate it
            # there specifically) -- so omit the line entirely rather than embed
            # a value that has no validated role for this backend.
            front_matter = "---\nread_refs: N/A\n---\n\n"
        else:
            # `self.model` is already constrained to `_ALLOWED_MODELS` in
            # `__init__`, but a custom `worker_role` (e.g. "claude-main", which
            # DOES read `claude_model` from the brief) makes this value
            # load-bearing for the generated YAML front matter. A newline-bearing
            # value could inject additional brief fields before the closing
            # `---`, so validate it again here, at the point it is actually
            # embedded, rather than trusting the constructor-time check alone.
            if not re.fullmatch(r"[a-zA-Z0-9.-]+", self.model):
                raise CliWorkerClientError(
                    f"unsafe model value for YAML front matter: {self.model!r}"
                )
            front_matter = f"---\nread_refs: N/A\nclaude_model: {self.model}\n---\n\n"

        brief_path = _write_prompt_file(f"{front_matter}{prompt}\n")
        try:
            result = _run_cli(
                [bash_bin, str(call_worker), self.worker_role, str(brief_path)],
                cwd=root,
                timeout_s=self.timeout_s,
            )
        except subprocess.TimeoutExpired as exc:
            raise CliWorkerError(f"call_worker.sh timed out after {self.timeout_s}s") from exc
        finally:
            brief_path.unlink(missing_ok=True)

        if not result.stdout.strip():
            raise CliWorkerError(
                f"call_worker.sh produced no envelope (rc={result.returncode}); "
                f"stderr: {result.stderr[-2000:]}"
            )
        try:
            envelope = json.loads(result.stdout)
        except json.JSONDecodeError as exc:
            raise CliWorkerError(
                f"call_worker.sh stdout is not a JSON envelope: {result.stdout[-2000:]}"
            ) from exc

        if envelope.get("status") != "ok":
            raise CliWorkerError(
                f"call_worker.sh returned status={envelope.get('status')!r} "
                f"(failure_class={envelope.get('failure_class')!r}, "
                f"exit_code={envelope.get('exit_code')!r}): "
                f"{str(envelope.get('stdout', ''))[:2000]}"
            )

        stdout_path = envelope.get("stdout_path")
        if stdout_path and Path(stdout_path).is_file():
            return Path(stdout_path).read_text(encoding="utf-8", errors="replace")
        return str(envelope.get("stdout", ""))

    # -- Track B: thin direct-CLI wrapper [REDACTED]

    def _run_track_b(self, prompt: str) -> str:
        brief_path = _write_prompt_file(prompt)
        try:
            wrapper_prompt = _file_prompt_wrapper(brief_path)
            cwd = _multiagent_root()
            input_str = None

            if self.backend == "claude":
                cmd = [
                    _resolve_executable("claude"),
                    "-p", wrapper_prompt,
                    "--model", self.model,
                    "--output-format", "json",
                    "--allowedTools", "Read,Grep,Glob,LS",
                ]
            else:
                # For Codex, avoid argv length limits by passing prompt via stdin
                cmd = [_resolve_executable("codex"), "exec", "-"]
                input_str = prompt

            try:
                result = _run_cli(cmd, cwd=cwd, timeout_s=self.timeout_s, input_str=input_str)
            except subprocess.TimeoutExpired as exc:
                raise CliWorkerError(
                    f"{self.backend} CLI timed out after {self.timeout_s}s -- confirm it is "
                    "logged in; headless calls cannot complete an interactive auth flow"
                ) from exc
        finally:
            brief_path.unlink(missing_ok=True)

        if result.returncode != 0:
            raise CliWorkerError(
                f"{self.backend} CLI exited {result.returncode}: {result.stderr[-2000:]}"
            )

        if self.backend == "codex":
            return result.stdout

        try:
            wrapper = json.loads(result.stdout)
        except json.JSONDecodeError as exc:
            raise CliWorkerError(
                f"claude --output-format json returned non-JSON: {result.stdout[-2000:]}"
            ) from exc
        text = wrapper.get("result")
        if not isinstance(text, str):
            raise CliWorkerError(f"unexpected claude JSON wrapper shape: {wrapper!r}")
        return text

## The one rule that governs everything you do

**You produce structured content. You never produce design.**

You emit JSON conforming to the Slide IR schema: a `layout_id` and the content that goes

## Content budgets ??this is not advice

Each layout's placeholders have a hard character budget, given to you below. The rendering

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""Typed mirror of ``ir/schema.json`` -- the IR contract, in Python.

The JSON Schema is the *normative* contract (it is what the LLM's tool-use call is
validated against, and it is language-neutral). This module is the *ergonomic* one: it
gives the renderer real objects instead of nested dicts, and it enforces the handful of
rules JSON Schema structurally cannot express:

  * every table row has exactly ``len(columns)`` cells;
  * ``layout_id`` names a layout that actually exists in ``layout_manifest.json``;
  * content fits the per-layout budget (delegated to :mod:`aippt.render.fit`).

Design note -- why stdlib dataclasses and not pydantic: the only hard dependency of this
project is python-pptx. The schema is already enforced at the model-output boundary by
``jsonschema``; a second, subtly-different validation dialect in the middle of the
pipeline would be a source of drift, not safety.

Round-trip invariant:  ``Deck.from_dict(d).to_dict() == d``  for any schema-valid ``d``
that has been normalised (i.e. after string-form rich text is expanded into runs).
"""

from __future__ import annotations

import json
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any, ClassVar

IR_VERSION = "1.0"
SCHEMA_PATH = Path(__file__).with_name("schema.json")


class IRValidationError(ValueError):
    """IR that is structurally wrong. Carries a path so the bounded-retry prompt can
    tell the model *exactly* which field to fix (e.g. ``slides[3].blocks[1].rows[2]``)."""

    def __init__(self, path: str, message: str) -> None:
        super().__init__(f"{path}: {message}")
        self.path = path
        self.message = message


# [REDACTED]
# Rich text
# [REDACTED]

@dataclass
class Run:
    """One styled span. ``code`` is the workhorse: 111 of them in the 30-slide corpus."""

    t: str
    b: bool = False
    i: bool = False
    code: bool = False
    link: str | None = None

    def to_dict(self) -> dict[str, Any]:
        out: dict[str, Any] = {"t": self.t}
        if self.b:
            out["b"] = True
        if self.i:
            out["i"] = True
        if self.code:
            out["code"] = True
        if self.link:
            out["link"] = self.link
        return out


@dataclass
class RichText:
    """A run sequence. Accepts the bare-string shorthand and normalises it.

    The shorthand exists for the LLM's benefit: asking a model to emit
    ``[{"t": "hello"}]`` when it means ``"hello"`` is a reliable source of malformed
    output. We accept both and normalise inward, so the renderer only ever sees runs.
    """

    runs: list[Run] = field(default_factory=list)

    @classmethod
    def parse(cls, raw: Any, path: str) -> RichText:
        if isinstance(raw, str):
            return cls([Run(t=raw)])
        if isinstance(raw, list):
            runs = []
            for i, r in enumerate(raw):
                if not isinstance(r, dict) or "t" not in r:
                    raise IRValidationError(f"{path}[{i}]", "each run needs a 't' field")
                runs.append(Run(t=r["t"], b=bool(r.get("b")), i=bool(r.get("i")),
                                code=bool(r.get("code")), link=r.get("link")))
            return cls(runs)
        raise IRValidationError(path, f"rich text must be a string or run array, got {type(raw).__name__}")

    @property
    def plain(self) -> str:
        """Style-stripped text. This -- not the run count -- is what the budget measures."""
        return "".join(r.t for r in self.runs)

    def to_dict(self) -> list[dict[str, Any]]:
        return [r.to_dict() for r in self.runs]

# Blocks
# [REDACTED]

@dataclass
class Block:
    """Base class. Subclasses set ``type`` and implement ``parse``/``to_dict``.

    ``text_length`` is the contract every block owes :mod:`aippt.render.fit`: the number
    of *rendered characters* it will consume. fit.py sums it across a slide's blocks and
    compares against the layout's content budget, without knowing what any block is.
    """

    type: ClassVar[str] = ""

    def text_length(self) -> int:
        raise NotImplementedError

    def to_dict(self) -> dict[str, Any]:
        raise NotImplementedError


@dataclass
class Heading(Block):
    type: ClassVar[str] = "heading"
    text: str = ""

    def text_length(self) -> int:
        return len(self.text)

    def to_dict(self) -> dict[str, Any]:
        return {"type": self.type, "text": self.text}


@dataclass
class Paragraph(Block):
    type: ClassVar[str] = "paragraph"
    text: RichText = field(default_factory=RichText)

    def text_length(self) -> int:
        return len(self.text.plain)

    def to_dict(self) -> dict[str, Any]:
        return {"type": self.type, "text": self.text.to_dict()}


@dataclass
class BulletItem:
    text: RichText
    level: int = 0


@dataclass
class Bullets(Block):
    type: ClassVar[str] = "bullets"
    items: list[BulletItem] = field(default_factory=list)

    def text_length(self) -> int:
        return sum(len(i.text.plain) for i in self.items)

    def to_dict(self) -> dict[str, Any]:
        return {"type": self.type,
                "items": [{"text": i.text.to_dict(), "level": i.level} for i in self.items]}


@dataclass
class Callout(Block):
    type: ClassVar[str] = "callout"
    text: RichText = field(default_factory=RichText)
    variant: str = "info"
    title: str | None = None

    def text_length(self) -> int:
        return len(self.text.plain) + len(self.title or "")

    def to_dict(self) -> dict[str, Any]:
        out: dict[str, Any] = {"type": self.type, "variant": self.variant,
                               "text": self.text.to_dict()}
        if self.title:
            out["title"] = self.title
        return out


@dataclass
class Table(Block):
    type: ClassVar[str] = "table"
    columns: list[str] = field(default_factory=list)
    rows: list[list[RichText]] = field(default_factory=list)
    caption: str | None = None

    def text_length(self) -> int:
        return (sum(len(c) for c in self.columns)
                + sum(len(cell.plain) for row in self.rows for cell in row))

    def to_dict(self) -> dict[str, Any]:
        out: dict[str, Any] = {
            "type": self.type,
            "columns": list(self.columns),
            "rows": [[c.to_dict() for c in row] for row in self.rows],
        }
        if self.caption:
            out["caption"] = self.caption
        return out


@dataclass
class CodeVariant:
    code: str
    label: str | None = None
    language: str | None = None


@dataclass
class Code(Block):
    type: ClassVar[str] = "code"
    variants: list[CodeVariant] = field(default_factory=list)

    def text_length(self) -> int:
        # Only the widest variant is ever shown at once, so budget against that one.
        return max((len(v.code) for v in self.variants), default=0)

    def to_dict(self) -> dict[str, Any]:
        items = []
        for v in self.variants:
            d: dict[str, Any] = {"code": v.code}
            if v.label:
                d["label"] = v.label
            if v.language:
                d["language"] = v.language
            items.append(d)
        return {"type": self.type, "variants": items}


@dataclass
class ImageSource:
    kind: str          # "data_uri" | "path"
    value: str


@dataclass
class Image(Block):
    type: ClassVar[str] = "image"
    source: ImageSource = field(default_factory=lambda: ImageSource("path", ""))
    alt: str = ""
    caption: str | None = None

    def text_length(self) -> int:
        # An image occupies area, not characters. It is budgeted by fit.py as an area
        # claim on the placeholder, not a character count.
        return len(self.caption or "")

    def to_dict(self) -> dict[str, Any]:
        out: dict[str, Any] = {
            "type": self.type,
            "source": {"kind": self.source.kind, "value": self.source.value},
            "alt": self.alt,
        }
        if self.caption:
            out["caption"] = self.caption
        return out


@dataclass
class Diagram(Block):
    type: ClassVar[str] = "diagram"
    source: str = ""
    syntax: str = "mermaid"
    kind: str | None = None
    render_hint: str = "auto"

    def text_length(self) -> int:
        return 0

    def to_dict(self) -> dict[str, Any]:
        out: dict[str, Any] = {"type": self.type, "syntax": self.syntax,
                               "source": self.source, "render_hint": self.render_hint}
        if self.kind:
            out["kind"] = self.kind
        return out


@dataclass
class StepItem:
    title: str
    text: RichText | None = None


@dataclass
class Steps(Block):
    type: ClassVar[str] = "steps"
    items: list[StepItem] = field(default_factory=list)

    def text_length(self) -> int:
        return sum(len(i.title) + (len(i.text.plain) if i.text else 0) for i in self.items)

    def to_dict(self) -> dict[str, Any]:
        items = []
        for i in self.items:
            d: dict[str, Any] = {"title": i.title}
            if i.text:
                d["text"] = i.text.to_dict()
            items.append(d)
        return {"type": self.type, "items": items}


@dataclass
class CardItem:
    title: str
    text: RichText | None = None
    tag: str | None = None


@dataclass
class Cards(Block):
    type: ClassVar[str] = "cards"
    items: list[CardItem] = field(default_factory=list)
    columns: int = 2

    def text_length(self) -> int:
        return sum(len(i.title) + (len(i.text.plain) if i.text else 0) for i in self.items)

    def to_dict(self) -> dict[str, Any]:
        items = []
        for i in self.items:
            d: dict[str, Any] = {"title": i.title}
            if i.text:
                d["text"] = i.text.to_dict()
            if i.tag:
                d["tag"] = i.tag
            items.append(d)
        return {"type": self.type, "columns": self.columns, "items": items}

# Block dispatch
# [REDACTED]

def _parse_block(raw: Any, path: str) -> Block:
    if not isinstance(raw, dict):
        raise IRValidationError(path, "block must be an object")
    btype = raw.get("type")

    if btype == "heading":
        return Heading(text=raw["text"])

    if btype == "paragraph":
        return Paragraph(text=RichText.parse(raw["text"], f"{path}.text"))

    if btype == "bullets":
        items = [BulletItem(text=RichText.parse(it["text"], f"{path}.items[{i}].text"),
                            level=int(it.get("level", 0)))
                 for i, it in enumerate(raw.get("items", []))]
        if not items:
            raise IRValidationError(path, "bullets block has no items")
        return Bullets(items=items)

    if btype == "callout":
        return Callout(text=RichText.parse(raw["text"], f"{path}.text"),
                       variant=raw.get("variant", "info"),
                       title=raw.get("title"))

    if btype == "table":
        columns = list(raw.get("columns", []))
        if not columns:
            raise IRValidationError(path, "table has no columns")
        rows: list[list[RichText]] = []
        for r, row in enumerate(raw.get("rows", [])):
            # The one rule JSON Schema cannot state: cell count must match column count.
            # A ragged row does not raise in python-pptx -- it silently drops cells or
            # throws deep in the XML layer, so we catch it here where the message is useful.
            if len(row) != len(columns):
                raise IRValidationError(
                    f"{path}.rows[{r}]",
                    f"row has {len(row)} cells but the table declares {len(columns)} columns")
            rows.append([RichText.parse(c, f"{path}.rows[{r}][{c_i}]")
                         for c_i, c in enumerate(row)])
        if not rows:
            raise IRValidationError(path, "table has no rows")
        return Table(columns=columns, rows=rows, caption=raw.get("caption"))

    if btype == "code":
        variants = [CodeVariant(code=v["code"], label=v.get("label"), language=v.get("language"))
                    for v in raw.get("variants", [])]
        if not variants:
            raise IRValidationError(path, "code block has no variants")
        return Code(variants=variants)

    if btype == "image":
        src = raw.get("source") or {}
        if src.get("kind") not in ("data_uri", "path"):
            raise IRValidationError(f"{path}.source.kind", "must be 'data_uri' or 'path'")
        return Image(source=ImageSource(kind=src["kind"], value=src["value"]),
                     alt=raw.get("alt", ""), caption=raw.get("caption"))

    if btype == "diagram":
        return Diagram(source=raw["source"], syntax=raw.get("syntax", "mermaid"),
                       kind=raw.get("kind"), render_hint=raw.get("render_hint", "auto"))

    if btype == "steps":
        items = [StepItem(title=it["title"],
                          text=RichText.parse(it["text"], f"{path}.items[{i}].text")
                          if "text" in it else None)
                 for i, it in enumerate(raw.get("items", []))]
        return Steps(items=items)

    if btype == "cards":
        items = [CardItem(title=it["title"],
                          text=RichText.parse(it["text"], f"{path}.items[{i}].text")
                          if "text" in it else None,
                          tag=it.get("tag"))
                 for i, it in enumerate(raw.get("items", []))]

                )
        return errors

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""Text fitting and overflow control. **The #1 design risk of this project.**

STATUS: specification only. Every function below raises NotImplementedError.

Why this module is the hard one
-------------------------------
PowerPoint's "shrink text on overflow" is not stored as a result, it is stored as an
*instruction* (``<a:normAutofit fontScale="..."/>``) that PowerPoint's layout engine
evaluates when it opens the file. python-pptx writes the instruction but cannot evaluate
it: it has no font metrics, no line breaker, no layout engine. So:

    text_frame.word_wrap = True
    text_frame.auto_size = MSO_AUTO_SIZE.TEXT_TO_FIT_SHAPE     # <- does NOT fit the text

Overflowing text does not error, does not warn, and does not visibly clip in the XML. It
simply renders off the bottom of the box. **Every deck this project generates is one
verbose LLM sentence away from a broken slide**, and nothing in the stack will tell you.

The three-layer defence
-----------------------
Layer 1 -- PREVENT (the only layer that actually scales).
    Inject the per-placeholder content budget into the author prompt. A model told
    "max 6 bullets x 9 words, title <= 42 Korean characters" mostly complies. This is
    cheap, it is upstream of everything, and it removes the problem rather than managing
    it. ``analyze_pptx_master.py`` computes these budgets; that is why it exists.

Layer 2 -- MEASURE + DEGRADE (this module).
    Before writing, estimate the rendered height. If it exceeds the box, degrade in a
    fixed, documented order (:func:`fit_text_frame`). Deterministic, no LLM in the loop.

Layer 3 -- VERIFY (render -> PNG -> check).
    Layers 1 and 2 both rest on an *estimate*. The only ground truth is a render.
    LibreOffice converts the .pptx to PNG; :func:`detect_overflow_in_png` checks whether
    ink appears where it should not. This is the authoritative check and the only one
    that catches a bad font-metric assumption.

A note on honesty: :func:`estimate_text_height` is a model, not a measurement. It will be
wrong sometimes. That is precisely why layer 3 exists and why the degradation ladder is
ordered to fail *safe* (smaller, then fewer) rather than to fail *pretty*.
"""

def visual_width(text: str, font_pt: float) -> float:
    """Rendered width of ``text`` in points, mixing scripts correctly.

        sum(font_pt * (CJK_CHAR_WIDTH_RATIO if is_cjk(c) else LATIN_CHAR_WIDTH_RATIO)
            for c in text)

    A per-character sum, not ``len(text) * ratio``: the corpus routinely mixes
    ("VEO_Focus_SetPosition() ?몄텧 ??紐⑦꽣媛 ?대룞?⑸땲??) and a single ratio for such a
