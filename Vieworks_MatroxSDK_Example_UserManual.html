Vieworks Matrox SDK Example User Manual

Matrox Rapixo CXP 기반 Vieworks 카메라 예제 프로그램의 고객 배포용 HTML 매뉴얼

Discovery, Open, Grab, Acquisition Mode, Buffer Control, Viewer, Save Scan Buffer

1. 문서 목적

이 문서는 Vieworks 카메라와 Matrox Rapixo CXP 프레임 그래버를 사용하는 예제 프로그램의 기본 조작 방법을 설명합니다.

대상 사용자: 본 예제코드를 처음 실행하는 고객, FAE, 장비 통합 담당자, SDK 동작 검증 담당자

사용자는 이 매뉴얼을 따라 카메라 검색, 카메라 Open, 획득 모드 선택, Grab 시작/정지, 버퍼 확인, Viewer 표시, Scan Buffer 저장, SDK Event Log 확인까지 순서대로 수행할 수 있습니다.

2. 예제 프로그램 개요

본 예제는 Matrox SDK를 통해 카메라를 검색하고, 선택한 카메라를 지정한 획득 조건으로 열어 영상을 수집하는 WinForms 기반 샘플입니다.

주요 조작

  • 연결된 Vieworks 카메라 검색
  • 기본 DCF 또는 사용자 DCF로 Camera Open
  • FreeRun, Manual Scan, External Trigger 모드 설정
  • DCF Sequence Grab / Continuous Grab 선택

확인 기능

  • 획득 프레임 수와 버퍼 진행률 표시
  • Viewer에 현재 프레임 또는 선택 프레임 표시
  • Scan Buffer 프레임 BMP 저장
  • SDK Event Log 확인

3. 실행 전 준비 사항

항목 확인 내용
카메라 연결 Vieworks 카메라가 CoaXPress 인터페이스로 Matrox Rapixo CXP 프레임 그래버에 연결되어 있어야 합니다.
전원 및 케이블 카메라 전원, CXP 케이블, 프레임 그래버 장착 상태를 확인합니다.
Matrox SDK/드라이버 Matrox 프레임 그래버 드라이버와 SDK가 정상 설치되어 있어야 합니다.
실행 환경 .NET Framework 4.7.2 기반 Windows 애플리케이션입니다.
DCF 파일 기본 Open은 CoaxPress_currentstate.dcf를 사용합니다. 별도 설정이 필요하면 .dcf 파일을 준비합니다.

5. 기본 조작 순서

  1. 1Discovery 버튼을 클릭합니다.
  2. 2검색된 카메라 목록에서 사용할 카메라를 선택합니다.
  3. 3필요 시 Image Buffer Control 값을 확인하거나 수정합니다.
  4. 4일반 Open 모드에서는 획득 모드와 Trigger Input Pin을 선택합니다.
  5. 5Open 또는 Open with DCF로 카메라를 엽니다.
  6. 6DCF Open 시 DCF Sequence Grab 또는 DCF Continuous Grab을 선택합니다.
  7. 7Grab을 클릭하여 획득을 시작합니다. Manual Scan에서는 필요 시 Start Scan을 클릭합니다.
  8. 8Viewer, Acquired Frames, ProgressBar, Event Log를 확인합니다.
  9. 9필요 시 AcqFrameScrollBar로 프레임을 확인하거나 Save Scan Buffer로 저장합니다.
  10. 10Stop 후 Close로 종료합니다.

7. Camera Discovery 영역

Discovery 버튼

  • Matrox Grabber SDK를 초기화합니다.
  • Matrox Rapixo CXP 프레임 그래버에 연결된 카메라를 검색합니다.
  • 검색 결과를 카메라 목록에 표시합니다.
  • 검색된 카메라가 하나 이상이면 첫 번째 카메라를 자동 선택합니다.

카메라 목록 컬럼

컬럼 설명
Grabber Idx프레임 그래버 인덱스입니다.
Camera Idx해당 그래버에 연결된 카메라 인덱스입니다.
Camera Model카메라 모델명입니다.
Vendor카메라 제조사입니다.
Serial #카메라 시리얼 번호입니다.
Interface카메라 인터페이스 정보입니다.
Grabber Model사용 중인 그래버 모델입니다.
카메라가 표시되지 않으면 카메라 전원, CXP 케이블, Matrox 드라이버, 프레임 그래버 인식 상태를 먼저 확인합니다.

8. Imaging Control 버튼

버튼 동작 주의 사항
Open 기본 CoaxPress_currentstate.dcf로 선택 카메라를 열고, 카메라 타입 추정, Width/Height 조회, 버퍼 할당, 초기 Acquisition Mode 적용을 수행합니다. Discovery 후 카메라가 선택된 상태에서 사용합니다.
Open with DCF 사용자가 선택한 .dcf 파일로 카메라를 엽니다. DCF 설정을 우선 사용합니다. 일반 모드/Trigger Pin은 비활성화되고 DCF Grab 방식 선택이 활성화됩니다.
Grab 현재 모드 또는 DCF Grab 방식에 따라 영상 획득을 시작합니다. Sequence Grab은 Scan Buffer Num에 도달하면 자동 정지됩니다.
Stop GrabStop 호출 후 정지 이벤트를 대기하고, 프레임 카운터와 ProgressBar를 초기화합니다. 모드 변경, 버퍼 변경, Close 전에는 Stop을 권장합니다.
Start Scan Manual Scan 또는 Sequence Grab 흐름에서 SDK StartScan 명령을 호출합니다. FreeRun에서는 일반적으로 별도 조작이 필요하지 않습니다.
Close Grab 중이면 정지 후 카메라 Close, 캡처 버퍼 해제, SDK/Grabber 해제, 카메라 목록 초기화를 수행합니다. Close 후 다시 사용하려면 Discovery부터 다시 진행합니다.

9. Acquisition Mode

FreeRun

  • 외부 트리거 없이 연속 획득합니다.
  • FrameStart/LineStart Trigger를 Off로 설정합니다.
  • TDI 계열은 AreaScan/Area 동작으로 설정합니다.

Manual Scan

  • 프레임 그래버 내부 트리거를 사용합니다.
  • LineScan 기준 내부 트리거 20 kHz, AreaScan 기준 30 fps를 사용합니다.
  • Grab 후 Start Scan으로 스캔을 시작합니다.

External Trigger

  • 외부 CXP 입력 신호를 트리거로 사용합니다.
  • 실제 배선에 맞는 Trigger Input Pin 선택이 중요합니다.
  • 현재 첨부된 DCF 기준 External Trigger 입력 기본값은 AUX_IO 2입니다.
  • AUX_IO 2는 DIFF 5V 입력 신호를 안정적으로 수신하기 때문에 External Trigger 테스트 시 우선 권장합니다.
  • 외부 신호가 없으면 프레임 카운트가 증가하지 않을 수 있습니다.
Grab 중 Acquisition Mode 변경은 허용되지 않습니다. 모드를 변경하려면 먼저 Stop을 클릭합니다.

10. Trigger Input Pin 및 DCF Grab

Trigger Input Pin

외부 트리거 입력으로 사용할 AUX_IO 핀을 선택합니다.

AUX_IO 0 AUX_IO 1 AUX_IO 2 AUX_IO 3 AUX_IO 4 AUX_IO 5 AUX_IO 6 AUX_IO 7

  • 카메라가 Open된 상태에서 값을 변경하면 SDK의 Signal Input Index가 즉시 변경됩니다.
  • 변경 결과는 SDK Event Log에 기록됩니다.
  • DCF Open 모드에서는 DCF 설정을 우선하므로 Trigger Input Pin 선택이 비활성화됩니다.
  • 현재 첨부된 DCF에는 External Trigger 입력 핀이 AUX_IO 2 기준으로 설정되어 있습니다.
  • DIFF 5V 입력을 사용하는 고객 환경에서는 AUX_IO 2가 입력 신호를 안정적으로 받기 때문에 권장 기본 핀으로 안내합니다.

DCF Sequence Grab / DCF Continuous Grab

항목 동작 사용 예
DCF Sequence Grab DCF Open 상태에서 Sequence Grab으로 획득합니다. Scan Buffer Num에 도달하면 자동 정지됩니다. 정해진 버퍼 개수만큼 이미지를 획득할 때
DCF Continuous Grab DCF Open 상태에서 Continuous Grab으로 획득합니다. 사용자가 Stop을 누를 때까지 계속 획득합니다. DCF 설정으로 연속 영상 흐름을 확인할 때

11. Image Buffer Control

중요: Image Buffer Control의 값은 고정 기본값으로 설명하지 않습니다. 카메라 Open 및 초기화 과정에서 SDK 이미지 콜백의 메타데이터 콜백이 먼저 전달되며, 이때 BufferIndex == -1로 들어오는 ImageCallback metadata index 정보를 기준으로 UI 값이 갱신됩니다.
컨트롤 설명
Image Width 획득 이미지의 가로 크기입니다. 카메라 또는 DCF 설정에 따라 실제 Width가 달라질 수 있습니다.
Image Height 획득 이미지의 세로 크기입니다. LineScan에서는 스캔 라인 누적 단위에 맞춰 확인합니다.
SDK Buffer Num Matrox SDK 내부 Grab 버퍼 개수로 사용됩니다.
Scan Buffer Num 전체 Grab 버퍼 개수이며 ProgressBar, ScrollBar, Sequence Grab 자동 정지 기준으로 사용됩니다.

버퍼가 재할당되면 내부 캡처 프레임 배열도 Scan Buffer Num 기준으로 다시 생성됩니다.

12. Viewer, ScrollBar, Save Buffer

Acquired Frames / ProgressBar

  • 이미지 콜백이 들어올 때마다 Acquired Frames가 증가합니다.
  • ProgressBar는 Scan Buffer Num 기준으로 현재 획득 위치를 표시합니다.
  • Stop 시 프레임 카운터와 ProgressBar가 초기화됩니다.

Viewer / AcqFrameScrollBar

  • 현재 콜백 프레임이 Viewer에 표시됩니다.
  • ScrollBar를 움직이면 해당 버퍼 인덱스의 프레임을 Viewer에 표시합니다.
  • 아직 저장되지 않은 인덱스는 비어 있을 수 있습니다.

Save Scan Buffer

  • 현재 메모리에 저장된 Scan Buffer 프레임을 BMP 파일로 저장합니다.
  • 파일명은 frame_000.bmp, frame_001.bmp 형식입니다.
  • 저장 성공/실패 개수는 SDK Event Log와 메시지 박스로 표시됩니다.

13. 권장 사용 시나리오

기본 연결 확인

  1. Discovery를 클릭하고 카메라가 표시되는지 확인합니다.
  2. Open을 클릭합니다.
  3. 필요 시 FreeRun으로 변경한 후 Grab을 클릭합니다.
  4. Acquired Frames와 Viewer 이미지가 갱신되는지 확인합니다.
  5. Stop, Close 순서로 종료합니다.

Manual Scan 테스트

  1. Manual Scan 선택 후 Open을 클릭합니다.
  2. Grab 후 Start Scan을 클릭합니다.
  3. ProgressBar, Viewer, Event Log를 확인합니다.
  4. 필요 시 Save Scan Buffer로 캡처 프레임을 저장합니다.

14. External Trigger / DCF 시나리오

External Trigger 테스트

  1. 외부 트리거 신호가 CXP 입력으로 연결되어 있는지 확인합니다.
  2. External Trigger를 선택합니다.
  3. 실제 배선에 맞는 Trigger Input Pin을 선택합니다. 현재 첨부 DCF 기준 권장 기본 핀은 DIFF 5V 입력 수신이 안정적인 AUX_IO 2입니다.
  4. Open, Grab 후 외부 트리거를 입력합니다.
  5. Acquired Frames와 Viewer가 트리거 입력에 따라 갱신되는지 확인합니다.

DCF 파일 기반 실행

  1. Open with DCF를 클릭합니다.
  2. 사용할 .dcf 파일을 선택합니다.
  3. DCF Sequence Grab 또는 DCF Continuous Grab을 선택합니다.
  4. Grab 후 Viewer, 프레임 카운트, Event Log를 확인합니다.
  5. 필요 시 Save Scan Buffer로 저장합니다.

15. 주의 사항 및 제한 사항

  • Discovery를 먼저 수행한 뒤 카메라를 Open해야 합니다.
  • Grab 중 Acquisition Mode 변경은 허용되지 않습니다.
  • Acquisition Mode 변경 전에는 Stop을 먼저 클릭합니다.
  • 버퍼 값 변경은 Camera Open 전 또는 Grab Stop 후 수행하는 것을 권장합니다.
  • Open with DCF 사용 시 DCF 설정이 우선 적용되며 일반 획득 모드와 Trigger Input Pin 선택은 비활성화됩니다.
  • DCF Open 상태에서는 DCF Sequence Grab 또는 DCF Continuous Grab으로 Grab 방식을 선택합니다.
  • LineScan 카메라는 UI의 Image Height 값이 실제 스캔 높이에 중요한 영향을 줍니다.
  • External Trigger 모드에서는 외부 트리거 신호가 없으면 프레임이 획득되지 않을 수 있습니다.
  • Trigger Input Pin 선택값은 실제 AUX_IO 배선과 일치해야 합니다.
  • 현재 첨부된 DCF의 External Trigger 기본 입력 핀은 AUX_IO 2이며, DIFF 5V 입력 신호 수신 안정성 때문에 AUX_IO 2 사용을 권장합니다.
  • Save Scan Buffer는 현재 메모리에 남아 있는 캡처 프레임만 저장합니다.

16. 문제 해결

증상 확인 사항
Discovery 후 카메라가 표시되지 않음카메라 전원, CXP 케이블, Matrox 드라이버, 그래버 인식 상태를 확인합니다.
Open 실패선택한 카메라, DCF 파일 존재 여부, 카메라 모델과 DCF 호환성을 확인합니다.
Grab 후 Acquired Frames가 증가하지 않음Acquisition Mode, 트리거 입력, 카메라 Open 상태, SDK Event Log를 확인합니다.
Viewer 이미지가 갱신되지 않음Acquired Frames가 증가하는지, 선택한 버퍼 인덱스에 프레임이 있는지, Event Log 오류가 있는지 확인합니다.
External Trigger에서 프레임이 들어오지 않음외부 신호 입력 여부와 Trigger Input Pin 선택이 실제 AUX_IO 배선과 일치하는지 확인합니다. 현재 첨부 DCF 기준 권장 기본 핀은 DIFF 5V 입력 수신이 안정적인 AUX_IO 2입니다.
Manual Scan에서 스캔이 시작되지 않음Grab 후 Start Scan을 눌렀는지 확인합니다.
DCF 모드에서 원하는 Grab 방식으로 동작하지 않음DCF Sequence Grab 또는 DCF Continuous Grab 선택 상태를 확인합니다.
모드 변경이 되지 않음Grab이 완전히 Stop된 뒤 다시 변경합니다.
버퍼 관련 오류 발생Image Width, Image Height, SDK Buffer Num, Scan Buffer Num 값이 양수인지 확인하고 메모리 사용량을 점검합니다.
Save Scan Buffer가 저장하지 못함캡처된 프레임이 있는지, 저장 폴더 쓰기 권한이 있는지 확인합니다.
