## The wire contract (both phases build to this)

`POST /api/generate`, JSON body:
```json
{ "prompt": "<non-empty>", "model": "<optional allowlisted id; omitted => server default>",
  "images": [ { "mime": "image/png", "data": "<base64, no data: prefix>" } ] }
```
`prompt` stays REQUIRED (empty/whitespace → 422 before any model call/sleep). `model` and `images` are OPTIONAL; omitting both behaves byte-for-byte like today (keeps existing `{"prompt": …}` tests green). Response unchanged: a `canvas-ir/1` deck handed to `loadIR()`.

## Assumptions & caveats (brief left these open)

1. **"Paste images into the textbox"** is interpreted as *multimodal input to the model* (images ride `/api/generate`, become Gemini image parts; ignored in mock mode). If the intent was to *insert the image onto the stage* instead, that's a different feature (`insertMedia('image', file)`) — confirm before building.
2. **"Extended" model id unconfirmed** — `gemini-3.5-flash-extended` is a placeholder matching the existing `gemini-3.5-flash` naming; the allowlist is the single change point.
3. **Multimodal SDK call** must be verified against the installed `google-genai`; it's behind the mocked `_call_gemini` seam, so unit tests pass regardless — smoke-test with a real key.
4. **JSON+base64 chosen over multipart** for `/api/generate` to preserve the existing JSON test suite and shared guard; revisit if very large images are expected (base64 inflates ~33%; cap is 50MB).
5. **`field-sizing: content`** is recent-Chromium only; the `scrollHeight` fallback is Gate-1-safe and covers older engines.
6. **Bottom bar spans stage+props columns**, not full width under the toolbar, to keep the toolbar's full-height span; a truly full-width composer would require re-rectangling the grid areas.
