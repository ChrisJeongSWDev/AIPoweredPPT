## What I verified against the installed library (reads were allowed)

These are not assumptions — I read `site-packages/pptx/`:

1. **`Part.drop_rel(rId)` deletes only if `_rel_ref_count(rId) < 2`**, and it counts references by XPath-ing `@r:id` over *that part's* XML (`opc/package.py:409-430`). The `<p:sldId r:id="…"/>` we are about to remove **is** the reference it counts. So `drop_rel()` **must** come before `sldIdLst.remove()`, exactly as the brief says. Reverse the order and the count is 0, `0 < 2` still holds, so it still deletes — but that's luck, not design; keep the documented order.
2. **`Presentation.slides` is a `lazyproperty`** (`presentation.py:108`) that runs `rename_slide_parts([sldId.rId for sldId in sldIdLst])` on first access. That is the landmine. The rule in the brief is correct and I follow it exactly.
3. **`ShadowFormat.inherit = False` *adds* an empty `<a:effectLst/>`** (`dml/effect.py:34-41` → `get_or_add_effectLst()`). It does not remove one.
4. **`new_autoshape_sp` hard-codes a `<p:style>` block** with `accent1` in `lnRef`/`fillRef`/`effectRef` and `lt1` in `fontRef` (`oxml/shapes/autoshape.py:269-282`).
5. **`CT_TextCharacterProperties` lists `a:ea` in `_tag_seq` but declares no `ZeroOrOne` for it** (`oxml/text.py:263-312`) — so `get_or_add_latin()` exists, `get_or_add_ea()` does not. The lxml `insert_element_before` recipe is required, and `insert_element_before` does exist (`oxml/xmlchemy.py:685`). The plan's successor list is schema-correct.
6. **`line.color` auto-sets solid fill** (`dml/line.py:21-33`), so `shp.line.color.rgb = …` is safe without a preceding `.fill.solid()`.

### Two plan bugs this surfaced (worth the Critic's attention)

- **`HTML_to_PPTX_Plan.md` §7.3 has the `effectLst` assertion inverted.** It asserts *"Inherited shadow `<a:effectLst>` on any renderer-created shape → **absent**"*. But `shadow.inherit = False` is precisely what *writes* an empty `<a:effectLst/>`, and that empty element is what breaks the inheritance link. The correct assertion is: **`<a:outerShdw>` absent AND `<a:effectLst>` present**. My `calibrate.py` asserts the correct pair.
- **The plan's four `add_shape` overrides are not enough to satisfy the plan's own `accent1` invariant.** §6.4 lists four overrides (fill, line, shadow, text) and §7.3 then demands *"`accent1` / `4472C4` in any renderer-created `<p:sp>` → **absent**"*. Overriding `spPr` wins at *render* time but leaves the `<p:style>` block — with its three literal `accent1` references — sitting in the XML. That assertion fails as written. There is a **fifth override**: remove the `<p:style>` element (`minOccurs="0"`, so this is schema-legal). I inline it in `calibrate.py` and flag that it must move into Phase 1's `style.py`.

### 1. `src/aippt/tools/make_renderer_template.py`

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""One-off build step. Produces reference/renderer_template.pptx (0 slides) and, from the
package it just built, reference/template_pin.json.

    python src/aippt/tools/make_renderer_template.py             # build + write the pin
    python src/aippt/tools/make_renderer_template.py --dry-run   # build in memory, write nothing

Two rules that are not negotiable:

* The source template is NEVER written back. It is opened, mutated in memory, and saved to a
  different path. If the source SHA does not match, we stop -- there is no --force.
* This module is NEVER imported from the request path. Private slide-deletion API is
  acceptable exactly once, in a build step (HTML_to_PPTX_Plan.md rule 3).

The layout signature in the pin is OBSERVED from the built package, never guessed. The plan's
expected values are asserted against reality; they are not copied into the pin.

Rebuilds are not byte-reproducible (ZIP entries carry timestamps), so the pin is on the
committed artifact. Re-pinning is deliberate: rebuild, audit, calibrate, commit (plan 4.3).
"""

from __future__ import annotations

import argparse
import hashlib
import json
import sys
from pathlib import Path
from typing import Any

from lxml import etree
from pptx import Presentation
from pptx.oxml.ns import qn

sys.path.insert(0, str(Path(__file__).resolve().parents[2]))  # src/ -- when run as a plain script
from aippt.package_audit import audit_file  # noqa: E402

# src/aippt/tools/make_renderer_template.py -> tools -> aippt -> src -> project root
PROJECT_ROOT = Path(__file__).resolve().parents[3]

SRC = PROJECT_ROOT / "Vieworks_R&D_ppt_Template.pptx"
DST = PROJECT_ROOT / "reference" / "renderer_template.pptx"
PIN = PROJECT_ROOT / "reference" / "template_pin.json"

SRC_SHA = "0de7d70cf45197e959d93c31eedd7599c42c23c1153d7b67b18d332141e61442"
BUILDER = "aippt.tools.make_renderer_template@1"

# Expected reality, per the plan. Asserted against the built package; NOT copied into the pin.
EXPECT_LAYOUT_INDEX = 3
EXPECT_LAYOUT_PARTNAME = "/ppt/slideLayouts/slideLayout4.xml"
EXPECT_MEDIA = {"image5.jpeg", "image2.svg"}

A_NS = "http://schemas.openxmlformats.org/drawingml/2006/main"

# p14:sectionLst lives under this ext uri. Sections index slide IDs; with zero slides they are
# stale, and a stale section list is a "PowerPoint wants to repair this file" prompt in waiting.
SECTION_LST_URI = "{521415D9-36F7-43E2-AB2F-B90AF26B5E84}"


class BuildError(RuntimeError):
    """Fail closed. A half-correct renderer template is worse than no renderer template."""


def sha256_file(path: Path) -> str:
    h = hashlib.sha256()
    with path.open("rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


def _delete_all_slides(prs: Presentation) -> int:
    """Drop every slide without touching prs.slides inside the loop.

    prs.slides is a lazyproperty that runs rename_slide_parts() over the rIds it finds in
    sldIdLst. Reach for it while the package is transiently inconsistent -- a sldId whose rel we
    already dropped -- and it raises KeyError. So: bind the sldIdLst element ONCE, iterate the
    element, and do not go back through the Slides collection until the loop has finished.

    drop_rel() BEFORE sldIdLst.remove(), in that order: Part.drop_rel() refuses to delete a
    relationship still referenced twice or more, and it counts references by scanning the part's
    XML for @r:id -- the <p:sldId r:id="..."/> we are about to remove is the reference it counts.
    """
    sld_id_lst = prs.slides._sldIdLst  # private, by necessity -- build step only
    removed = 0
    for sld_id in list(sld_id_lst):
        rId = sld_id.get(qn("r:id"))
        prs.part.drop_rel(rId)      # presentation.xml.rels -> slideN.xml, gone
        sld_id_lst.remove(sld_id)   # <p:sldId> entry, gone
        removed += 1
    # The slide parts are now unreachable from the relationship graph, so python-pptx will not
    # serialize them -- and neither will the notesSlide parts hanging off them.
    return removed


def _strip_stale_slide_indexes(prs: Presentation) -> list[str]:
    """Remove presentation-level structures that index slides by id. With 0 slides they dangle,
    and package_audit.py will not catch them: it checks r:-namespaced ids, and these are not."""
    stripped: list[str] = []
    root = prs._element

    cust_show_lst = root.find(qn("p:custShowLst"))
    if cust_show_lst is not None:
        root.remove(cust_show_lst)
        stripped.append("p:custShowLst")

    for ext_lst in root.findall(qn("p:extLst")):
        for ext in list(ext_lst.findall(qn("p:ext"))):
            if ext.get("uri") == SECTION_LST_URI:
                ext_lst.remove(ext)
                stripped.append("p14:sectionLst")
        if len(ext_lst) == 0:
            root.remove(ext_lst)
    return stripped


def _layout_media(layout: Any) -> list[str]:
    names = set()
    for rel in layout.part.rels.values():
        if rel.is_external:
            continue
        names.add(Path(str(rel.target_partname)).name)
    return sorted(names)


def _theme_accent1(prs: Presentation) -> str | None:
    """accent1 is the colour add_shape() hands you if you do not override it. Observe it, so the
    pin can name the exact value that must never appear in generated content."""
    for rel in prs.slide_master.part.rels.values():
        if rel.is_external or not rel.reltype.endswith("/theme"):
            continue
        try:
            root = etree.fromstring(rel.target_part.blob)
        except Exception:
            return None
        srgb = root.find(
            f"{{{A_NS}}}themeElements/{{{A_NS}}}clrScheme/{{{A_NS}}}accent1/{{{A_NS}}}srgbClr"
        )
        return srgb.get("val") if srgb is not None else None
    return None


def observe_signature(prs: Presentation) -> dict:
    """Read the layout signature off the built package. This is the reality we pin."""
    layout = prs.slide_layouts[EXPECT_LAYOUT_INDEX]
    ph = layout.placeholders[10]
    return {
        "layout_index": EXPECT_LAYOUT_INDEX,
        "layout_name": layout.name,
        "layout_partname": str(layout.part.partname),
        "slide_width_emu": int(prs.slide_width),
        "slide_height_emu": int(prs.slide_height),
        "slide_count": len(prs.slides),
        "layout_count": len(prs.slide_layouts),
        "placeholder_idxs": sorted(p.placeholder_format.idx for p in layout.placeholders),
        "placeholder_10_emu": {
            "left": int(ph.left),
            "top": int(ph.top),
            "width": int(ph.width),
            "height": int(ph.height),
        },
        "required_media": _layout_media(layout),
    }


def check_built_package(dst: Path) -> dict:
    """The plan's 2.3 acceptance gate, minus the two checks only a human can make (opens cleanly
    in PowerPoint; the page number on an added slide reads 1). Those live in HUMAN_VERIFICATION.md."""
    prs = Presentation(str(dst))
    sig = observe_signature(prs)

    failures: list[str] = []
    if sig["slide_count"] != 0:
        failures.append(f"slides survived deletion: {sig['slide_count']}")
    if sig["layout_count"] != 5:
        failures.append(f"layout count is {sig['layout_count']}, expected 5")
    if (sig["slide_width_emu"], sig["slide_height_emu"]) != (12192000, 6858000):
        failures.append(f"slide size changed: {sig['slide_width_emu']}x{sig['slide_height_emu']}")
    if sig["layout_partname"] != EXPECT_LAYOUT_PARTNAME:
        failures.append(f"layout 3 partname is {sig['layout_partname']}, expected {EXPECT_LAYOUT_PARTNAME}")
    if sig["placeholder_idxs"] != [10]:
        failures.append(f"layout 3 placeholder idxs are {sig['placeholder_idxs']}, expected [10]")
    missing = EXPECT_MEDIA - set(sig["required_media"])
    if missing:
        failures.append(f"layout 3 lost media {sorted(missing)}; it has {sig['required_media']}")

    dangling = audit_file(dst)
    if dangling:
        failures.append(f"{len(dangling)} dangling relationship(s): {dangling[:5]}")

    if failures:
        raise BuildError("built package failed the acceptance gate:\n  - " + "\n  - ".join(failures))

    sig["_theme_accent1"] = _theme_accent1(prs)
    return sig


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(
        description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter
    )
    ap.add_argument("--dry-run", action="store_true", help="build and inspect, but write nothing")
    args = ap.parse_args(argv)

    if not SRC.exists():
        raise BuildError(f"source template not found: {SRC}")
    lock = SRC.with_name("~$" + SRC.name)
    if lock.exists():
        print(
            f"warning: {lock.name} exists -- the template may be open in PowerPoint. "
            "Close it before trusting this build.",
            file=sys.stderr,
        )

    src_sha = sha256_file(SRC)
    if src_sha != SRC_SHA:
        raise BuildError(
            f"source template changed.\n  expected {SRC_SHA}\n  actual   {src_sha}\n"
            "Every layout fact in the plan was measured against the expected package. "
            "Re-measure before re-pinning; there is no --force."
        )

    prs = Presentation(str(SRC))  # SRC is never saved back
    removed = _delete_all_slides(prs)
    stripped = _strip_stale_slide_indexes(prs)

    if args.dry_run:
        print(json.dumps({"dry_run": True, "slides_removed": removed, "stripped": stripped}, indent=2))
        return 0

    DST.parent.mkdir(parents=True, exist_ok=True)
    prs.save(str(DST))

    sig = check_built_package(DST)
    accent1 = sig.pop("_theme_accent1")

    pin = {
        "pin_version": 1,
        "source_template": {
            "filename": SRC.name,
            "sha256": src_sha,
            "bytes": SRC.stat().st_size,
        },
        "renderer_template": {
            "filename": "reference/renderer_template.pptx",
            "sha256": sha256_file(DST),
            "bytes": DST.stat().st_size,
            "built_from_sha256": src_sha,
            "builder": BUILDER,
        },
        "layout_signature": sig,
        "theme": {
            "accent1": accent1,
            "note": "Office blue. add_shape() defaults to it. MUST NOT appear in a generated shape.",
        },
    }
    PIN.parent.mkdir(parents=True, exist_ok=True)
    PIN.write_text(json.dumps(pin, indent=2, ensure_ascii=False) + "\n", encoding="utf-8")

    print(f"slides removed       : {removed}")
    print(f"stale indexes stripped: {stripped or 'none'}")
    print(f"renderer template    : {DST.relative_to(PROJECT_ROOT).as_posix()}")
    print(f"pin                  : {PIN.relative_to(PROJECT_ROOT).as_posix()}")
    print()
    print(json.dumps(pin, indent=2, ensure_ascii=False))
    return 0


if __name__ == "__main__":
    try:
        raise SystemExit(main())
    except BuildError as exc:
        print(f"BUILD FAILED: {exc}", file=sys.stderr)
        raise SystemExit(1) from exc
```

### 3. `src/aippt/canvas/pin.py`

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""The template pin: byte identity + structural signature, both fail-closed.

Three functions, deliberately separate:

    load_pin()                   -> dict           read and shape-check reference/template_pin.json
    verify_pin(pin)              -> None           the two gates; raises TemplatePinError
    open_renderer_template(pin)  -> Presentation   verify, then open. The only sanctioned way in.

Nothing here falls back to another layout, another template, or another anything. A pin mismatch
is a stop, not a warning: silently rendering onto a different layout ships a subtly-wrong deck,
which is strictly worse than a loud failure.

Call verify_pin() once at process start, not per request.

    python src/aippt/canvas/pin.py     # verify the committed pin and print what it pins
"""

from __future__ import annotations

import hashlib
import json
import sys
from pathlib import Path

from pptx import Presentation

# src/aippt/canvas/pin.py -> canvas -> aippt -> src -> project root
PROJECT_ROOT = Path(__file__).resolve().parents[3]
PIN_PATH = PROJECT_ROOT / "reference" / "template_pin.json"

_REQUIRED_TOP = ("pin_version", "renderer_template", "layout_signature")
_REQUIRED_SIG = (
    "layout_index",
    "layout_partname",
    "slide_width_emu",
    "slide_height_emu",
    "slide_count",
    "layout_count",
    "placeholder_idxs",
    "placeholder_10_emu",
    "required_media",
)


class TemplatePinError(RuntimeError):
    """Fail closed. Never fall back to another layout."""


def sha256_file(path: Path) -> str:
    h = hashlib.sha256()
    with path.open("rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


def load_pin() -> dict:
    """Read reference/template_pin.json and check its shape. Does not touch the .pptx."""
    if not PIN_PATH.exists():
        raise TemplatePinError(
            f"pin file not found: {PIN_PATH}\n"
            "Build it: python src/aippt/tools/make_renderer_template.py"
        )
    try:
        pin = json.loads(PIN_PATH.read_text(encoding="utf-8"))
    except json.JSONDecodeError as exc:
        raise TemplatePinError(f"pin file is not valid JSON: {PIN_PATH}: {exc}") from exc

    if pin.get("pin_version") != 1:
        raise TemplatePinError(
            f"unsupported pin_version {pin.get('pin_version')!r}; this code reads version 1"
        )
    missing = [k for k in _REQUIRED_TOP if k not in pin]
    if missing:
        raise TemplatePinError(f"pin file is missing required key(s): {missing}")
    missing_sig = [k for k in _REQUIRED_SIG if k not in pin["layout_signature"]]
    if missing_sig:
        raise TemplatePinError(f"pin layout_signature is missing key(s): {missing_sig}")
    if "sha256" not in pin["renderer_template"] or "filename" not in pin["renderer_template"]:
        raise TemplatePinError("pin renderer_template needs both 'filename' and 'sha256'")
    return pin


def renderer_template_path(pin: dict) -> Path:
    """The pin stores a project-relative path. Resolve it against the project root, never the
    process cwd -- the request path must not depend on where the server was started from."""
    return PROJECT_ROOT / pin["renderer_template"]["filename"]


def verify_pin(pin: dict) -> None:
    """Two gates, both mandatory.

    Gate 1 -- byte identity. Catches an edited, re-saved or swapped renderer template.
    Gate 2 -- structural signature. Catches a re-pinned-but-wrong package: someone rebuilt from a
              different source, updated the SHA, and shipped a deck whose layout 3 is not our
              layout 3. Gate 1 alone would wave that through.

    The SOURCE template is deliberately not hashed here. It may be open in PowerPoint (the ~$ lock
    file), it is not needed at render time, and reading it per-request buys nothing.
    """
    tpl = renderer_template_path(pin)
    if not tpl.exists():
        raise TemplatePinError(
            f"renderer template not found: {tpl}\n"
            "Build it: python src/aippt/tools/make_renderer_template.py"
        )

    # --- Gate 1: byte identity -------------------------------------------------------------
    expected = pin["renderer_template"]["sha256"]
    actual = sha256_file(tpl)
    if actual != expected:
        raise TemplatePinError(
            f"renderer template SHA mismatch\n"
            f"  expected {expected}\n"
            f"  actual   {actual}\n"
            "Rebuild via aippt.tools.make_renderer_template and RE-PIN deliberately. "
            "Rebuilds are not byte-reproducible (ZIP timestamps), so a rebuilt-but-unpinned "
            "template lands here even when it is structurally identical -- that is intended."
        )

    # --- Gate 2: structural signature -------------------------------------------------------
    prs = Presentation(str(tpl))
    sig = pin["layout_signature"]

    checks: list[tuple[bool, str]] = [
        (len(prs.slides) == sig["slide_count"],
         f"slide count is {len(prs.slides)}, pinned {sig['slide_count']}"),
        (len(prs.slide_layouts) == sig["layout_count"],
         f"layout count is {len(prs.slide_layouts)}, pinned {sig['layout_count']}"),
        (int(prs.slide_width) == sig["slide_width_emu"],
         f"slide width is {int(prs.slide_width)}, pinned {sig['slide_width_emu']}"),
        (int(prs.slide_height) == sig["slide_height_emu"],
         f"slide height is {int(prs.slide_height)}, pinned {sig['slide_height_emu']}"),
    ]
    for ok, msg in checks:
        if not ok:
            raise TemplatePinError(f"layout signature mismatch: {msg}")

    idx = sig["layout_index"]
    if not 0 <= idx < len(prs.slide_layouts):
        raise TemplatePinError(f"layout index {idx} is out of range")
    layout = prs.slide_layouts[idx]

    checks = [
        (str(layout.part.partname) == sig["layout_partname"],
         f"layout {idx} partname is {layout.part.partname}, pinned {sig['layout_partname']}"),
        (sorted(p.placeholder_format.idx for p in layout.placeholders) == sig["placeholder_idxs"],
         f"layout {idx} placeholder idx set is "
         f"{sorted(p.placeholder_format.idx for p in layout.placeholders)}, "
         f"pinned {sig['placeholder_idxs']}"),
    ]

    got_media = {
        Path(str(r.target_partname)).name
        for r in layout.part.rels.values()
        if not r.is_external
    }
    checks.append((
        set(sig["required_media"]) <= got_media,
        f"layout {idx} lost media: pinned {sig['required_media']}, has {sorted(got_media)}",
    ))
    for ok, msg in checks:
        if not ok:
            raise TemplatePinError(f"layout signature mismatch: {msg}")

    try:
        ph = layout.placeholders[10]
    except KeyError as exc:
        raise TemplatePinError(
            f"layout signature mismatch: layout {idx} has no placeholder idx 10 -- "
            "the title has nowhere to go"
        ) from exc

    exp = sig["placeholder_10_emu"]
    got = {"left": int(ph.left), "top": int(ph.top),
           "width": int(ph.width), "height": int(ph.height)}
    if got != exp:
        raise TemplatePinError(
            f"layout signature mismatch: placeholder idx 10 geometry moved\n"
            f"  pinned {exp}\n  actual {got}"
        )


def open_renderer_template(pin: dict) -> Presentation:
    """Verify, then open. This is the only sanctioned way to get a Presentation for rendering --
    it is not possible to open the template without passing both gates first."""
    verify_pin(pin)
    return Presentation(str(renderer_template_path(pin)))


def main() -> int:
    try:
        pin = load_pin()
        verify_pin(pin)
    except TemplatePinError as exc:
        print(f"PIN VERIFY FAILED\n{exc}", file=sys.stderr)
        return 1
    sig = pin["layout_signature"]
    print("pin OK")
    print(f"  renderer template : {pin['renderer_template']['filename']}")
    print(f"  sha256            : {pin['renderer_template']['sha256']}")
    print(f"  layout {sig['layout_index']}          : {sig['layout_name']} -> {sig['layout_partname']}")
    print(f"  placeholders      : {sig['placeholder_idxs']}")
    print(f"  media             : {sig['required_media']}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""Phase 0, step 2 -- the calibration slide. Turns "I think the mapping is right" into a number.

    python src/aippt/tools/calibrate.py [-o reference/calibration.pptx]

Emits a one-slide deck from the PINNED renderer template using layout 3, so the logo, gradient
divider and page number are inherited (not drawn). The slide carries every case that catches a
coordinate or style bug:

  * four rectangles flush to the exact slide corners  -> origin and sign errors
  * stroke widths 0, 1, 4 and 8 logical units         -> box-model drift. Stroke is CENTRED on the
                                                         path in DrawingML and in SVG; it is NOT
                                                         part of w/h. A CSS border would be drawn
                                                         inward and drift by stroke/2.
  * 30 deg and 45 deg rotation                        -> centre-origin mismatches
  * a known string in a known-width box at 14 pt      -> wrap-point and text-inset drift
  * a mixed KO/EN string                              -> the latin/ea font split

It then reopens the saved file and machine-checks the round trip (plan 7.3).

PHASE 0 IS DELIBERATELY ISOLATED. canvas/geometry.py and canvas/style.py are Phase 1. The EMU
conversion and the add_shape overrides below are INLINED here on purpose so that nothing from
Phase 1 needs to exist for this to run. When Phase 1 lands they move out and this file imports
them; the duplication is temporary and intentional.

The corner rectangles deliberately sit inside FOOTER_RESERVED (bottom-right) and flush to the
slide edges. This is a measurement fixture, not a product deck -- the reserved-region rejection
is a Phase-1 renderer rule and does not apply to it.
"""

from __future__ import annotations

import argparse
import sys
from pathlib import Path

from pptx.dml.color import RGBColor
from pptx.enum.shapes import MSO_SHAPE
from pptx.enum.text import MSO_ANCHOR, MSO_AUTO_SIZE, PP_ALIGN
from pptx.oxml.ns import qn
from pptx.util import Emu, Pt

sys.path.insert(0, str(Path(__file__).resolve().parents[2]))  # src/ -- when run as a plain script
from aippt.canvas.pin import load_pin, open_renderer_template  # noqa: E402

PROJECT_ROOT = Path(__file__).resolve().parents[3]
DEFAULT_OUT = PROJECT_ROOT / "reference" / "calibration.pptx"

# --- inlined from what will become canvas/geometry.py -------------------------------------------
EMU_PER_UNIT = 12700  # 1 logical unit == 1 pt == exactly 12700 EMU. 12192000/960 == 6858000/540.


def emu(u: float) -> Emu:
    """The single conversion. Integer, exact, zero drift."""
    return Emu(round(u * EMU_PER_UNIT))


# --- inlined from what will become canvas/style.py ----------------------------------------------
LATIN = "Century Gothic"
EA = "맑은 고딕"          # Century Gothic has no Hangul glyphs. This split is not optional.

RED = "FF0032"            # the default for new content
BLACK = "000000"
WHITE = "FFFFFF"
OFFICE_BLUE = "4472C4"    # what add_shape() hands you. Must never survive to the output.

TEXT_MARGIN_LR = Pt(7.2)  # PowerPoint's default text-frame insets: 0.1in L/R, 0.05in T/B.
TEXT_MARGIN_TB = Pt(3.6)  # Set them explicitly on BOTH sides; the CSS in the editor mirrors these.
LINE_SPACING = 1.2


def set_run_fonts(run, latin: str = LATIN, ea: str = EA) -> None:
    """python-pptx cannot express an East-Asian typeface: Font.name writes only <a:latin>, and
    CT_TextCharacterProperties declares no ZeroOrOne for a:ea (it is in _tag_seq, but there is no
    get_or_add_ea). So we drop to lxml. a:ea must follow a:latin and precede a:cs and friends."""
    rPr = run._r.get_or_add_rPr()
    rPr.get_or_add_latin().typeface = latin
    ea_el = rPr.find(qn("a:ea"))
    if ea_el is None:
        ea_el = rPr.makeelement(qn("a:ea"), {})
        rPr.insert_element_before(
            ea_el, "a:cs", "a:sym", "a:hlinkClick", "a:hlinkMouseOver", "a:rtl", "a:extLst"
        )
    ea_el.set("typeface", ea)


def drop_theme_style(shape) -> None:
    """THE FIFTH OVERRIDE, and the one the plan's four-override list in 6.4 misses.

    new_autoshape_sp hard-codes a <p:style> block pointing lnRef/fillRef/effectRef at
    schemeClr accent1 and fontRef at lt1. Overriding fill, line, shadow and text at the spPr level
    wins at RENDER time -- but the <p:style> element, with its three literal 'accent1' references,
    stays in the XML. The plan's own 7.3 invariant ("accent1 absent from any renderer-created
    <p:sp>") therefore fails unless we remove it. <p:style> is minOccurs=0, so removing it is
    schema-legal, and we set every property it would have supplied explicitly anyway.

    This belongs in Phase 1's canvas/style.py.
    """
    sp = shape._element
    style = sp.find(qn("p:style"))
    if style is not None:
        sp.remove(style)


def style_text_frame(tf, paragraphs: list[str] | None, *, size: float = 14.0,
                     color: str = WHITE, align: PP_ALIGN = PP_ALIGN.CENTER) -> None:
    tf.margin_left = tf.margin_right = TEXT_MARGIN_LR
    tf.margin_top = tf.margin_bottom = TEXT_MARGIN_TB
    tf.word_wrap = True                       # == CSS white-space: pre-wrap
    tf.auto_size = MSO_AUTO_SIZE.NONE         # the human sizes the box; no autofit, ever
    tf.vertical_anchor = MSO_ANCHOR.MIDDLE    # == CSS align-items: center

    if not paragraphs:
        return
    tf.clear()
    for i, text in enumerate(paragraphs):
        p = tf.paragraphs[0] if i == 0 else tf.add_paragraph()
        p.alignment = align
        p.space_before = Pt(0)                # explicit -- do not inherit
        p.space_after = Pt(0)
        p.line_spacing = LINE_SPACING         # == CSS line-height: 1.2
        run = p.add_run()
        run.text = text
        run.font.size = Pt(size)              # 1:1 with the model. No scale factor.
        run.font.bold = False
        run.font.italic = False
        run.font.color.rgb = RGBColor.from_string(color)
        set_run_fonts(run)                    # latin + ea


def add_shape(slide, prst, x, y, w, h, *, fill=RED, stroke=None, stroke_w=0.0,
              rotation=0.0, paragraphs=None, text_size=14.0, text_color=WHITE):
    """add_shape() plus the five overrides. Nothing is left to inherit."""
    shp = slide.shapes.add_shape(prst, emu(x), emu(y), emu(w), emu(h))
    shp.rotation = rotation                                   # degrees CW, about the centre

    drop_theme_style(shp)                                     # 5. accent1 refs out of the XML

    shp.fill.solid()                                          # 1. kills fillRef -> accent1
    shp.fill.fore_color.rgb = RGBColor.from_string(fill)

    if stroke is not None and stroke_w > 0:                   # 2. kills lnRef -> accent1
        shp.line.color.rgb = RGBColor.from_string(stroke)     # (also sets the line fill to solid)
        shp.line.width = Pt(stroke_w)
    else:
        shp.line.fill.background()                            # explicit "no line", not inherited

    shp.shadow.inherit = False                                # 3. kills effectRef -> drop shadow.
                                                              #    This WRITES an empty <a:effectLst/>;
                                                              #    that empty element IS the fix.
    style_text_frame(shp.text_frame, paragraphs,              # 4. kills fontRef -> lt1 + theme font
                     size=text_size, color=text_color)
    return shp


# --- the fixture --------------------------------------------------------------------------------
TITLE = "Phase 0 Calibration — 보정 슬라이드"

# 10 short identical tokens in a 200-unit box at 14 pt. The exact line count is not the assertion;
# AGREEMENT between the browser preview and the rendered PPTX is. Count the lines in both.
WRAP_TEXT = "wrap wrap wrap wrap wrap wrap wrap wrap wrap wrap"
MIXED_TEXT = "Vieworks 뷰웍스 AF Camera 자동 초점 Multi Exposure 다중 노출"

CORNER_W, CORNER_H = 40.0, 24.0


def build(slide) -> list[dict]:
    """Draw the fixture. Returns the expected geometry, for the round-trip check."""
    expected: list[dict] = []

    def rec(shp, x, y, w, h, rotation=0.0):
        expected.append({"shape": shp, "x": x, "y": y, "w": w, "h": h, "rotation": rotation})

    # 1. corners -- flush to 0 and to 960/540. Origin and sign errors show up here or nowhere.
    for x, y in ((0.0, 0.0),
                 (960.0 - CORNER_W, 0.0),
                 (0.0, 540.0 - CORNER_H),
                 (960.0 - CORNER_W, 540.0 - CORNER_H)):
        shp = add_shape(slide, MSO_SHAPE.RECTANGLE, x, y, CORNER_W, CORNER_H, fill=RED)
        rec(shp, x, y, CORNER_W, CORNER_H)

    # 2. stroke widths 0 / 1 / 4 / 8. The stroke bleeds stroke/2 OUTSIDE the box on every side;
    #    x/y/w/h must be identical across all four despite the visibly different outlines.
    for i, sw in enumerate((0.0, 1.0, 4.0, 8.0)):
        x, y, w, h = 60.0 + i * 170.0, 110.0, 120.0, 60.0
        shp = add_shape(slide, MSO_SHAPE.RECTANGLE, x, y, w, h,
                        fill=RED, stroke=BLACK, stroke_w=sw,
                        paragraphs=[f"stroke {sw:g}"], text_size=11)
        rec(shp, x, y, w, h)

    # 3. rotation, about the centre, degrees clockwise -- same convention as CSS rotate().
    for x, deg in ((60.0, 30.0), (240.0, 45.0)):
        y, w, h = 200.0, 120.0, 60.0
        shp = add_shape(slide, MSO_SHAPE.RECTANGLE, x, y, w, h, fill=RED,
                        rotation=deg, paragraphs=[f"{deg:g}°"], text_size=11)
        rec(shp, x, y, w, h, deg)

    # 4. known wrap: 200 wide, minus 7.2 of inset on each side == 185.6 of text width at 14 pt.
    x, y, w, h = 420.0, 300.0, 200.0, 110.0
    shp = add_shape(slide, MSO_SHAPE.RECTANGLE, x, y, w, h, fill=WHITE,
                    stroke=BLACK, stroke_w=1.0,
                    paragraphs=[WRAP_TEXT], text_size=14, text_color=BLACK)
    rec(shp, x, y, w, h)

    # 5. mixed KO/EN -- Century Gothic for the Latin, Malgun Gothic for the Hangul, in one run.
    x, y, w, h = 660.0, 300.0, 240.0, 110.0
    shp = add_shape(slide, MSO_SHAPE.RECTANGLE, x, y, w, h, fill=WHITE,
                    stroke=BLACK, stroke_w=1.0,
                    paragraphs=[MIXED_TEXT], text_size=14, text_color=BLACK)
    rec(shp, x, y, w, h)

    return expected


def set_title(slide, text: str) -> None:
    """Layout 3 has no semantic TITLE placeholder, so slide.shapes.title is None. Key by idx."""
    try:
        ph = slide.placeholders[10]
    except KeyError as exc:
        raise SystemExit(
            "layout 3 did not clone placeholder idx 10 -- the title has nowhere to go"
        ) from exc
    tf = ph.text_frame
    tf.text = text
    p = tf.paragraphs[0]
    p.alignment = PP_ALIGN.LEFT
    run = p.runs[0]
    run.font.size = Pt(30)                                # the layout says 30; say it anyway
    run.font.bold = False
    run.font.color.rgb = RGBColor.from_string(BLACK)
    set_run_fonts(run)                                    # do NOT trust the inherited placeholder style


def check_round_trip(out: Path, expected: list[dict]) -> list[str]:
    """Reopen and assert against the model (plan 7.3). Reopening is the point: it is the round trip
    through serialisation that turns an in-memory inconsistency into a real defect."""
    from pptx import Presentation

    prs = Presentation(str(out))
    failures: list[str] = []

    if len(prs.slides) != 1:
        failures.append(f"slide count is {len(prs.slides)}, expected exactly 1")
        return failures
    slide = prs.slides[0]

    if not str(slide.slide_layout.part.partname).endswith("slideLayout4.xml"):
        failures.append(f"slide relates to {slide.slide_layout.part.partname}, expected slideLayout4.xml")

    drawn = [s for s in slide.shapes if not s.is_placeholder]
    if len(drawn) != len(expected):
        failures.append(f"{len(drawn)} drawn shapes on the reopened slide, expected {len(expected)}")
        return failures

    for i, (shp, exp) in enumerate(zip(drawn, expected)):
        for attr, unit in (("left", "x"), ("top", "y"), ("width", "w"), ("height", "h")):
            want = round(exp[unit] * EMU_PER_UNIT)
            got = int(getattr(shp, attr))
            if got != want:                                # 0 EMU tolerance. Exact, by construction.
                failures.append(f"shape[{i}].{attr}: {got} EMU, expected {want} EMU")
        if abs(float(shp.rotation) - exp["rotation"]) > 1e-6:
            failures.append(f"shape[{i}].rotation: {shp.rotation}, expected {exp['rotation']}")

        xml = shp._element.xml
        if OFFICE_BLUE in xml or "accent1" in xml:
            failures.append(f"shape[{i}]: Office blue survived -- accent1/{OFFICE_BLUE} in the XML")
        if "outerShdw" in xml:
            failures.append(f"shape[{i}]: inherited drop shadow survived (<a:outerShdw>)")
        if "effectLst" not in xml:
            failures.append(
                f"shape[{i}]: no <a:effectLst> -- shadow.inherit=False did not take. "
                "The EMPTY effectLst element is what breaks the inheritance link; its "
                "presence is the pass condition, not its absence (plan 7.3 has this inverted)."
            )
        for p in shp.text_frame.paragraphs:
            for run in p.runs:
                rPr = run._r.find(qn("a:rPr"))
                if rPr is None or rPr.find(qn("a:latin")) is None:
                    failures.append(f"shape[{i}]: run {run.text[:16]!r} has no <a:latin>")
                elif rPr.find(qn("a:ea")) is None:
                    failures.append(f"shape[{i}]: run {run.text[:16]!r} has no <a:ea> -- Hangul will "
                                    "fall back to whatever PowerPoint feels like")
    return failures


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(description=__doc__,
                                 formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("-o", "--out", type=Path, default=DEFAULT_OUT,
                    help=f"output deck (default: {DEFAULT_OUT.relative_to(PROJECT_ROOT).as_posix()})")
    args = ap.parse_args(argv)

    pin = load_pin()
    prs = open_renderer_template(pin)                     # both gates, or we do not get here
    layout = prs.slide_layouts[pin["layout_signature"]["layout_index"]]
    slide = prs.slides.add_slide(layout)                  # logo + divider + page number, inherited

    set_title(slide, TITLE)
    expected = build(slide)

    args.out.parent.mkdir(parents=True, exist_ok=True)
    prs.save(str(args.out))

    from aippt.package_audit import audit_file
    dangling = audit_file(args.out)

    failures = check_round_trip(args.out, expected)
    failures += [f"dangling relationship: {d}" for d in dangling]

    print(f"calibration deck: {args.out.relative_to(PROJECT_ROOT).as_posix()}")
    print(f"shapes drawn    : {len(expected)}")
    if failures:
        print(f"\nROUND-TRIP FAILED ({len(failures)}):", file=sys.stderr)
        for f in failures:
            print(f"  - {f}", file=sys.stderr)
        return 1

    print("round-trip      : PASS (0 EMU drift, no Office blue, no inherited shadow, latin+ea on "
          "every run, 1 slide, layout 4)")
    print("\nThe deterministic half is green. The raster half is NOT -- see HUMAN_VERIFICATION.md.")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## The checklist

### 1. PowerPoint opens `reference/renderer_template.pptx` clean

- [ ] Opens with **no "PowerPoint found a problem… would you like us to repair it?" prompt**.
      That prompt is the whole reason this check exists: LibreOffice will happily render a deck
      PowerPoint refuses, so a clean LibreOffice render proves nothing here.
- [ ] The deck is **empty** — zero slides in the thumbnail pane.
- [ ] View → Slide Master shows **5 layouts**, and layout 3 (`2_사용자 지정 레이아웃`) still has its
      logo, its gradient divider and its page-number field.

### 2. Page number on a slide added from layout 3 reads **"1"**

- [ ] Open `reference/calibration.pptx` (it is one slide, added from layout 3).
- [ ] The page number in the bottom-right reads **`1`** — **not `24`**.

      This is the check the whole Phase-0 template rebuild exists for. The source template ships
      23 slides; `add_slide()` on it appends a 24th, and the inherited page-number field would
      read 24. If you see 24 here, the renderer template was not actually slide-free and
      everything downstream is wrong.

- [ ] The **title reads `Phase 0 Calibration — 보정 슬라이드`**, sits in the inherited title band
      (not in a box we drew), and the Hangul renders as Hangul — not as boxes or tofu.

### 3. The SVG logo survives the conversion path

python-pptx puts the Vieworks wordmark in as an SVG (`image2.svg`) with a raster fallback carried
in the `svgBlip` extension. **Converters differ in which one they honour.** This is the single most
likely inheritance surprise in the whole project, and it cannot be checked structurally — the
relationship being present proves nothing about what comes out the other end.

- [ ] In **PowerPoint**: the red Vieworks wordmark is visible, top-right, **undistorted** (not
      stretched, not squashed, not a grey box, not missing).
- [ ] Through the **actual conversion path you will ship** (LibreOffice → PDF/PNG, or whatever the
      export pipeline really is): convert `reference/calibration.pptx` and confirm the wordmark is
      **still there and still undistorted**.
- [ ] The gradient divider (`image5.jpeg`) is visible and undistorted in **both**.

If the SVG drops out of the conversion path, say so now — it changes the asset strategy, and it is
far cheaper to find out here than in Phase 1D.

### 4. Raster diff ≤ 2 px

This is the acceptance number for the coordinate mapping. Coordinate equality proves the
*transform*; only this proves the *render*.

- [ ] Render `reference/calibration.pptx` to PNG at **960 × 540** via the real target consumer.
- [ ] Measure shape edges against the model coordinates. Every edge must be within **≤ 2 px**.

Specifically, on the calibration slide:

| What to look at | What it catches | Pass |
|---|---|---|
| The four corner rectangles | origin and sign errors | flush to the slide edges, no gap, no clipping |
| The stroke 0 / 1 / 4 / 8 row | **box-model drift** | all four *fills* start and end at identical x; the outlines grow **outward** from a fixed box, they do not shrink it. Stroke is centred on the path, bleeding stroke/2 on every side — it is **not** part of w/h. A shape whose fill shifts as the stroke thickens means someone imported CSS `box-sizing` semantics. |
| The 30° and 45° rectangles | centre-origin mismatch | rotated **about their centres**, not a corner |
| The "wrap wrap wrap…" box | wrap-point / text-inset drift | **count the lines.** The number itself is not the assertion — *agreement between the browser preview and the PPTX* is. A one-line difference here is the 7.2/3.6-unit text-frame inset trap. |
| The mixed KO/EN box | the latin/ea font split | Latin in **Century Gothic**, Hangul in **맑은 고딕** — in the *same run*, with no tofu |

> **The corner and bottom-right rectangles deliberately violate the reserved regions.** This is a
> measurement fixture, not a product deck. Reserved-region rejection is a Phase-1 renderer rule and
> does not apply to `calibrate.py`.

- [ ] **Record the measured error bar.** "≤ 2 px" is the gate; the actual number is what you quote
      from here on. Do not write "WYSIWYG" anywhere without pointing at it.

Not blockers for Phase 0, but they get more expensive the longer they wait:

- **D-1 — Century Gothic is not the Vieworks brand font.** The template's real design fonts are

## Assumptions and caveats

- **Nothing was executed.** I could not run the builder, so `reference/renderer_template.pptx` and `reference/template_pin.json` do not exist, and the renderer-template SHA is not knowable until someone runs it. The 2.3 acceptance gate is *coded*, not *passed*. The whole point of gate 2.3 is that the `drop_rel` + `sldIdLst.remove` recipe is unrun — it is still unrun.
- **`template_pin.json` is deliberately not hand-authored** (brief requirement 3). The builder observes the signature off the package it just built and writes the pin. Hand-writing it would be the exact failure the requirement forbids.
- **`calibrate.py` output path** is not specified in the brief. I defaulted to `reference/calibration.pptx` (next to the renderer template, overridable with `-o`), on the reasoning that `reference/` is already where generated-and-committed artifacts live and `artifacts/` is orchestrator-owned stdout capture.
- **`pin.py`'s three functions match the brief's signatures exactly** (`load_pin() -> dict`, `verify_pin(pin: dict) -> None`, `open_renderer_template(pin: dict) -> Presentation`). Paths resolve against a module-derived `PROJECT_ROOT`, never the process cwd, so the request path does not depend on where the server was started.
- **Phase 0 isolation is respected**: no `canvas/geometry.py`, no `canvas/style.py`. The EMU conversion, the `add_shape` overrides and the latin/ea split are inlined in `calibrate.py` with a comment marking each as Phase-1 relocation targets.
- **I added one thing the plan does not mention:** the builder strips `p:custShowLst` and `p14:sectionLst` from `presentation.xml`. Both index slides *by slide id*, so with zero slides they dangle — and `package_audit.py` will **not** catch them, because it only checks `r:`-namespaced ids and these are not. If the template has no sections this is a no-op; if it does, it is the difference between a clean open and a repair prompt. Cheap insurance, and it prints what it stripped.
